# 要带什么 —— 打包清单（2026-09-22 版）

> **这份在回答什么**：9/24 出发（**只剩 2 天**），一趟行李要同时扛完两段完全不同的旅行：
> 前 13 天是 **4 人北欧自驾**（奥斯陆 → 冰岛南岸 → 罗弗敦 → 特罗姆瑟极光，实测 **5–11°C、阵风 60 km/h、多雨**），
> 10/6 奥斯陆分手后是 **Steve 一个人的南欧 9–10 晚**（尼斯 **18–23°C 还能游泳** → 里斯本/马拉喀什 → 伦敦），
> 而且**每天晚上 19:00–01:00 要跟美西上班**。
> 行程出处：[`PLAN-final.md`](PLAN-final.md)（前段）· [`SOLO-after-oslo.md`](SOLO-after-oslo.md) 第九轮（后段）。
>
> **一句话**：这趟的难点不是"带什么"，是**一个箱子要覆盖 5°C 极光夜到 23°C（若去摩洛哥 30°C+）的海边**，
> 而且**中间没有机会回家换装**。所以主线是 **分层穿 + 压缩袋 + 路上洗一次衣服**，不是多带。

## 2. 衣服 —— 一套三层，穿越 5→23°C

**原则：不带"某地专用"的厚重单品，带能叠的层。**

### 必带（北欧段的核心，缺一样会难受一整天）
- [ ] **硬壳冲锋衣**（防风 + 真防水，带帽）—— 冰岛 60 km/h 阵风里，雨伞是废物，**伞会被吹烂，别带伞**
- [ ] **防水长裤 / 雨裤**（套在外面那种）—— Seljalandsfoss 瀑布后面、黑沙滩、Stokksnes 全是横着打的水沙
- [ ] **羽绒或 Primaloft 中层**（可压缩成一个拳头）—— 白天当外套、极光夜当内层
- [ ] **抓绒**一件
- [ ] **美利奴羊毛长袖 ×2 + 羊毛长裤袜 ×1** —— 唯一能穿 3 天不臭的东西，行李压缩的关键
- [ ] **羊毛袜 ×4**（厚 2 薄 2）
- [ ] **防水徒步鞋**（已磨合过的；Vestrahorn/Stokksnes 是湿沙滩）
- [ ] **毛线帽 + 围巾/脖套 + 手套**（🔴 手套要**能触屏**那种，不然每次拍极光都要脱手套）
- [ ] **泳衣 + 快干毛巾 + 拖鞋** —— 用得比你想的多：**蓝湖 Premium、9/28 热浴缸+桑拿、罗弗敦按摩浴缸+桑拿、10/5 小屋桑拿、尼斯海里**
- [ ] **眼罩**（罗弗敦/特罗姆瑟的住处遮光常不行）
- [ ] **太阳镜**（北纬 10 月太阳角度极低，开车正对着晃眼）

### 南欧段（10/6 之后，一个人）
- [ ] 短袖 ×2–3、薄长裤 ×1、轻薄夹克 ×1
- [ ] **一套体面的**（衬衫 + 休闲裤 + 一双不是徒步鞋的鞋）—— 尼斯老城/伦敦的餐厅够用，也能应付临时的正式场合
- [ ] 伦敦要一件**防水外壳**（就是上面那件硬壳，不用另带）

### 行李压缩三招
1. **压缩袋**装厚的那几件（冲锋衣/羽绒/抓绒）
2. **10/6 在奥斯陆分手时，把纯北欧的重物交给同伴带回北京**（如果你带了冰爪、雪地靴、羽绒裤这类后半段完全用不上的东西）。⚠️ 交出去就回不来了，只交真的不心疼的
3. **在尼斯洗一次衣服**（住 3–4 晚、整套 Airbnb 基本有洗衣机）→ 内衣袜子按 4–5 天带，不是 20 天

## 3. 电子 + 工作（🔴 这趟是"带着工作旅行"，这一节和衣服同等重要）

10/6 之后**每个工作日 19:00–01:00（伦敦 18:00–24:00）要在住处上班**，所以网络和桌面是硬需求。

- [ ] 笔记本 + 充电器（**多带一根线**，欧洲买同款线很贵）
- [ ] **GaN 多口充电器 ×1**（一个插座喂全部设备）
- [ ] **插头转换器**：北欧/法/葡/摩 = **C/F 型**；**英国 = G 型（完全不同，必须另有一个）**
- [ ] **一条短电源板/一转多**（欧洲住处插座常只有一两个，还在床头）
- [ ] **移动电源**（≤100 Wh，**必须随身，不能托运**）
- [ ] **车充 + 手机车架 + 长充电线** —— 冰岛/罗弗敦整天导航，手机会边用边掉电
- [ ] **eSIM**（见 §0）+ 🔴 **热点当工作备份**：住处 Wi-Fi 掉线时能把 6 小时班救回来
- [ ] 便携鼠标（连开 6 小时，触控板会让你恨自己）、**降噪耳机**（11 小时洲际 + 会议）
- [ ] **相机 + 三脚架**（极光唯一刚需，4 人共用一个也行）+ **备用电池 ×2，贴身放**（0°C 掉电极快）+ 快门线或用定时
- [ ] **头灯**（最好有红光档）—— 极光夜找路、看相机按钮；白光会毁掉同伴的夜视
- [ ] 转换卡的读卡器 / 移动硬盘（13 天 4K 素材）
- [ ] 10/5 那台 **保时捷 Macan 是纯电** → 装好充电 app（挪威 Recharge / Mer / Plugsurfing），**出发前确认 Konglehytta 小屋有没有充电位**；线一般在车上

## 4. 自驾 + 自炊（4 人整栋房，全程 10 晚自己做饭）

- [ ] **调料小包**：盐/胡椒/辣椒粉/一小瓶酱油/老干妈或辣酱/茶包咖啡 —— 北欧超市有食材没有你的味道，而且贵
- [ ] **保温杯 ×人手一个**（车上一整天）+ 折叠水壶（冰岛自来水直接喝，别买瓶装水）
- [ ] 快煮的干货：方便面/挂面/榨菜（连开 6 小时后不想做饭那晚的保险）
- [ ] 车里：垃圾袋、湿巾、厨房纸、**大塑料袋**（装湿衣服/湿鞋）
- [ ] 手机支架、**行车用的备用现金**（挪威/冰岛基本无现金，但渡轮和小停车场偶有例外）
- [ ] 🔴 **冰岛保险要在 Avis 柜台买那份零自付全险**（不是 DiscoverCars 的 Full Coverage），砂石险 + 沙尘/火山灰险必买
- [ ] Senja 渡轮（10/4 周日）班表出发前一周核 **Torghatten Nord / Entur**，手机装 Entur app

- [ ] 常用处方药（原包装 + 处方照片）

## 7. 按"最容易被忘记"排序的 Top 10

1. **英国 ETA**（不办登不上回程机）
2. **带 PIN 的信用卡**（冰岛加不了油）
3. **英国 G 型插头**（只带欧标会在伦敦傻眼）
4. **触屏手套**（极光夜每次拍照都要脱手套的痛）
5. **相机备用电池**（0°C 一小时报废一块）
6. **泳衣**（5 处桑拿/热浴缸 + 蓝湖 + 地中海）
7. **防水裤**（冰岛瀑布和黑沙滩会从下往上打湿你）
8. **行李秤**（Widerøe 小飞机随身只 10 kg）
9. **热点/备用网**（工作日晚上断网 = 直接影响上班）
10. **调料包**（13 天自炊，这一小袋的幸福感回报率最高）

## 8. 不要带
雨伞（会被吹烂）· 重型雪地靴/冰爪（9–10 月不需要，且后半段全是负担）· 吹风机（住处都有）·
瓶装水（冰岛/挪威自来水更好）· 太多现金 · 第二个三脚架（4 人一个够）
