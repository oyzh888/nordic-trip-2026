# 要带什么 —— 打包清单（2026-09-22 · 已合并 Steve 上次 Tahoe 那份）

> **这份在回答什么**：9/24 出发（**只剩 2 天**），一趟行李要扛完两段完全不同的旅行：
> 前 13 天 **4 人北欧自驾**（奥斯陆 → 冰岛南岸 → 罗弗敦 → 特罗姆瑟极光，实测 **5–11°C、阵风 60 km/h、多雨**），
> 10/6 奥斯陆分手后是 **一个人的南欧 9–10 晚**（尼斯 **18–23°C 能游泳** → 里斯本/马拉喀什 → 伦敦），
> 而且 **10/6 之后每个工作日晚上 19:00–01:00 要跟美西上班**。
> 行程出处：[`PLAN-final.md`](PLAN-final.md) · [`SOLO-after-oslo.md`](SOLO-after-oslo.md) 第九轮。
>
> **一句话**：难点不是"带什么"，是**一个箱子要覆盖 5°C 的极光夜到 23°C 能游泳的地中海**（去摩洛哥还有 30°C+），
> 而且中间**没机会回家换装**。所以主线是 **三层穿 + 压缩袋 + 在尼斯洗一次衣服**，不是多带。
>

### 🚁 无人机 —— 上次清单里有"无人机储存卡"，这趟有三条硬规则
1. 🔴 **摩洛哥禁止无人机入境，海关会当场没收**（若选方案 C 就**别带**）。
2. 🔴 **冰岛的招牌机位基本都禁飞**：Jökulsárlón 冰河湖、Vatnajökull 国家公园、Reynisfjara 黑沙滩一带均需许可或全面禁飞。
3. 欧盟/挪威走 **EASA 规则**：要**运营者注册 + A1/A3 在线考试 + 机身贴注册号**，挪威也照此执行。
→ **建议：这趟不带**（禁飞区覆盖了你最想飞的地方，收益远小于麻烦）；真要带就先办 EASA 注册，且方案 C 出局。

### 🔴 10/2 那班小飞机的实操（Widerøe 随身 ~10 kg，会被抽查）
MBP + iPad + 显示屏 + 相机 + 充电宝 + 线材，很容易破 10 kg。那天这样分：
- **随身**：所有**电池类**（充电宝、相机/无人机电池、笔电、iPad）—— 锂电池不许托运
- **托运**：不含电池的重物（**便携显示屏**、充电器、线材、三脚架、镜头）
