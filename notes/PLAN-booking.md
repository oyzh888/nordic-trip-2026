## 0. 先说三个结论（会改变要订什么，所以放最前面）

### ① 「2 个卫生间」是整个需求里最难满足的一条 —— 北欧酒店几乎没有

酒店套房基本都是 1 卫。能真正拿到 2 卫的只有三条路：

| 路子 | 典型形态 | 代价 |
|---|---|---|
| **A. 公寓 / aparthotel（2 房 2 卫）** | Tromsø 的 Enter Tromsø / Modern Tromsø Apartments、雷市 Reykjavik Residence 的 Two-Bedroom Two-Bathroom | 最贴需求，但库存最少、这个时间点最容易被订完 |
| **B. 大号 rorbu（罗弗敦特有）** | Svinøya Rorbuer 的 **Rorbu M+ / L+** 明确 2 卫；Hattvika Lodge 部分小屋 2 卫 | 罗弗敦唯一稳的 2 卫来源 |
| **C. 两间相连酒店房（connecting rooms）** | Thon Hotel Polar、Radisson Blu Tromsø「Family Stay = 2 connected rooms」 | **2 个卫生间自动成立**，常常比一套 2 卫公寓还便宜，代价是没厨房 |

👉 **建议：预算区间（2000–4000 RMB/room ≈ €250–500）在 C 方案下非常宽松，在 A 方案下刚好，
在旺季的罗弗敦/特罗姆瑟只够下限。** 所以默认策略是 **A 优先、抢不到就 C 兜底**，
而不是死守「必须一套带 2 卫的公寓」。

### ② 行程有三处「地理上打结」的地方，会决定订哪家酒店 —— 建议先定了再订房

| 位置 | 问题 | 建议改法 |
|---|---|---|
| **D4→D5（9/28→9/29）** | D4 住 Keflavík，D5 要跑斯奈山半岛再晚上飞奥斯陆。Keflavík → Ytri-Tunga 单程就 ~2h，绕完半岛（草帽山/黑教堂/海豹滩）再回 KEF 还车 ≈ 全天 8–9h 纯开车 + 赶飞机 | **D4 改住 Borgarnes 或 Akranes**（黄金圈/蓝湖结束后北上 1–1.5h），D5 半岛就近切入，还车前有余量。或者干脆**砍掉斯奈山**，D5 留在雷市轻松走 |
| **D3（9/27）蓝冰洞** | **天然蓝冰洞一般 11 月才开**（瓦特纳冰川）。9 月能做的是 **Katla 冰洞**（Mýrdalsjökull 冰川下，从 Vík 出发，全年开）或冰川徒步 | 若换 Katla，集合点在 **Vík** 而不是 Skaftafell → **D2/D3 的住宿位置要跟着改** |
| **D6（9/30）EVE 落地 10:35 → Reine** | EVE→Reine **约 290 km / 4h15**，加 Henningsvær 绕路和拍照，到 Reine 已近黑 | D6 住 **Svolvær / Henningsvær 一侧**，D7 再挪到 Reine；或 D6/D7 都住中部（Leknes/Ballstad）少搬一次箱子 |

### ③ 关于第 3 条（treg.to）—— **这个工具跟旅行完全无关，不建议装**

`treg.to/people-search` 是一个 **B2B 销售线索 / SEO 数据聚合平台**：找人的工作邮箱、电话、
公司信息，接的是 Apollo / Hunter / People Data Labs / Semrush / Moz / 各家广告后台。
官网自己写的目标用户是「SEO experts, media buyers, and SDRs」。

- **覆盖范围里没有任何旅行、酒店、租车、机票类数据源**（我把它首页的 provider 清单拉下来核过）。
- 用起来还要 GitHub/Google 登录、进 `/app` 配 provider API key、往里充钱（按结果计费 $0.0089/条起）。
- 它宣传的 78.2% vs 43% 准确率提升，衡量的是**「找人」任务**，不是「找酒店/租车」。

**对比结论：第 2 条（普通检索）在这个任务上完胜，第 3 条是走错门。**
真正需要补的不是「人物搜索」，而是**能跑 JS 的浏览器去读实时报价**（见下面 Phase 2）——
这个我本机已经有 Playwright + Chromium，不需要装任何第三方付费服务。

## 2. 执行计划

### Phase 1 —— 定 3 个决策（需要 Steve/Kevin 回答，约 10 分钟）

1. **几个人、怎么分房？** 直接决定是订「1 套 2 卫公寓」还是「2 间连通房」，也决定预算够不够。
2. **谁开车、用哪国驾照？**
   🔴 **中国驾照是个真问题**：中国不是《日内瓦/维也纳公约》成员国，**中国大陆无法签发国际驾照(IDP)**，
   市面上卖的「国际驾照」多数无效。挪威/冰岛租车公司通常接受 **中国驾照 + 公证/认证英文翻译**，
   但**必须逐家确认**，且翻译件 3 周内要办出来。若有美国驾照，直接免掉这一整摊。
3. **冰岛 D4/D5 那个结（上面 ②）怎么解？** 决定 D4 订 Keflavík 还是 Borgarnes。

## 3. 已经查实、可以直接当结论用的部分（不用再查）

### 冰岛租车（9/26–9/29，KEF 取 / KEF 还）
- **2WD 够用**（全程铺装路，不走 F 路），但**建议 AWD**（Duster / RAV4）—— 9 月末大风暴雨、可能早雪。
- **冬胎 11/1 才强制**，这个日期不需要。
- **保险必买 SCDW + GP + SAAP**。冰岛的碎石打玻璃 / 火山沙尘暴磨车漆是标准 CDW **不赔**的。
  ⛔ **别指望信用卡自带 CDW** —— 冰岛这两类损失基本被排除，且要先自己垫付再申请报销。
- **4 天 AWD + 全险 + 第二驾驶员 ≈ €450–700**（约 67,000–104,000 ISK），另有 2026 新增
  道路税约 1,400–1,550 ISK/天。
- **在 KEF 取车比在雷市取更划算**（冰岛没有明显机场附加费；反而机场大巴 €30/人×4 更贵）。
  雷市取 / KEF 还会产生 **~€50 异地费**。
- 口碑：**Blue / Go / Lava / Lotus**（本地，评价稳）；Hertz/Avis/Europcar/Sixt 和 Geysir 评价两极
  （柜台加保推销、车况、损伤争议）。**Blue 有还车钥匙箱、Go/Lotus 24h 还车** → 9/29 晚上还车没问题。

### 罗弗敦租车（9/30 EVE 取 → 10/2 Svolvær 还）
- EVE 机场有 **Hertz / Avis / Sixt / Europcar / Budget / Enterprise**；**Avis / Hertz / Sixt / Budget
  在 Svolvær 有点**，可异地还。本地 **Rent a Car Lofoten**（Svolvær）官网明确写支持 EVE 取还，是很强的选项。
- **异地还车费 500–1,500+ NOK**，不标准化，必须逐家问。
- 3 天紧凑型/中型 SUV ≈ **3,000–6,000 NOK**（不含异地费）。
- **EVE→Svolvær 165 km / ~2h30**；**EVE→Reine 290 km / ~4h15**。E10 全程**无渡轮、基本无收费站**。
- 交规要点：**全天开近光灯**、乡道默认 80、测速摄像和区间测速极多（超 10 km/h 罚款 >2,500 NOK）、
  **酒驾 0.02% 近乎零容忍**、单车道 møteplass 会车（上坡优先，别停在会车位）、注意驯鹿和羊。

### Senja（10/5）
- **自驾比跟团便宜**：跟团 1,990（Best Arctic 半自助）/ 2,000（Arctic Explorers）/ 2,900–3,400（FRAM）/
  3,750（Northern Norway Travel）NOK **每人**；自驾 1 天车 700–1,500 NOK + 渡轮 228 NOK/车/单程 + 油
  ≈ **1,500–2,500 NOK 一车**。挪威租车基本**不限里程**。
- 两条路：**Brensholmen→Botnhamn 渡轮**（10 月低季仍开，参考 08:45/10:45/15:00/17:00 出，
  回程 08:00/09:45/14:00/16:00，**出发前必查 Torghatten Nord 官网**）单程约 1h45–2h，更快更美但绑班次；
  或走 **Finnsnes / Gisund 大桥** 陆路 ~2h30–3h，时间自由。
- **10/5 特罗姆瑟日出 ~07:25 / 日落 ~18:15**（约 10h50 日照）。500 km 往返可行但是硬仗：
  在路上 5–6h，只剩 4–5h 玩 → **原行程写的 07:00 出发是对的**。
